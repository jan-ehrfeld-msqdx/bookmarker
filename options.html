Bookmarker

Files written: bookmarks.json, history.json and tabs.json in that folder (overwritten on every sync; a daily copy of the previous version is kept in a backups subfolder).

Restore

Pick a file previously written by this extension (e.g. from the target folder or its backups folder). Syncs overwrite the files in the target folder, so restore from a backup copy if the current files are already out of date.

Bookmarks

Imported into a new "Restored …" folder inside Other bookmarks; nothing existing is changed.

History

Browsers cannot add visits with their original dates, so this merges the file into the extension's accumulated history, which is what history.json is written from. It does not change the browser's own history page.

Open tabs

Reopens tabs in new windows, including pinned state and tab groups (Chrome/Brave). Browser-internal pages are skipped.
